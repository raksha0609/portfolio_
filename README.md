# Raksha Shivamogga Gopalakrishna — Portfolio

Personal portfolio website showcasing my work in AI, data science, computer vision, and software engineering.

## Tech Stack

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
- Framer Motion

## Running Locally

Requires Node.js & npm.

```sh
# Install dependencies
npm i

# Start the development server
npm run dev

# Build for production
npm run build
```
